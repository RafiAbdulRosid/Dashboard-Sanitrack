🚀 SaniTrack Dashboard
Pemetaan Pola Sanitasi dan Air Bersih Antarprovinsi Menggunakan K-Medoids & DTW

📌 Gambaran Umum
SaniTrack adalah dashboard monitoring untuk memetakan akses air bersih dan sanitasi di Indonesia. Proyek ini menggunakan metode K-Medoids Clustering berbasis Dynamic Time Warping (DTW) untuk mengelompokkan provinsi berdasarkan tren data panel 2019-2025 guna mendukung target SDG 6.

🌟 Fitur Utama
Clustering Analisis: Pengelompokan wilayah berdasarkan pola tren data (DTW).
Visualisasi Disparitas: Monitoring kesenjangan akses air bersih vs sanitasi aman.
Intervensi Presisi: Rekomendasi kebijakan berdasarkan karakteristik tiap klaster.

🛠️ Teknologi
Frontend: HTML5, CSS3, JavaScript.=
Library: Chart.js / ApexCharts.
Methodology: K-Medoids Clustering & Dynamic Time Warping.
